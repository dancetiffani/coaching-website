# Photos go here

Upload your photos into this folder (e.g. `hero.jpg`, `coach.jpg`, `food-1.jpg`).
Then, in the page, replace a placeholder box like

    <div class="photo">📷 Your main photo here</div>

with

    <img class="photo" src="images/hero.jpg" alt="Short description of the photo">

Tip: keep photos under ~500 KB each so the site loads fast on phones.
